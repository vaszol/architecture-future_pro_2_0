# Карта рисков трансформации «Будущее 2.0»

## 1. Архитектурные риски

| ID | Риск                                                 | Вероятность | Влияние | Описание                                                                                   |
|----|------------------------------------------------------|-------------|---------|--------------------------------------------------------------------------------------------|
| A1 | Отказ легаси-систем до завершения миграции           | Средняя     | Высокое | SQL Server 2008 может выйти из поддержки. Критическая бизнес-логика в хранимых процедурах. |
| A2 | Потеря данных при миграции                           | Низкая      | Высокое | Ошибки в ETL-процессах, неконсистентность при двойной записи.                              |
| A3 | Деградация производительности в near-real-time       | Средняя     | Среднее | Потоковая обработка не справляется с пиковыми нагрузками.                                  |
| A4 | Проблемы с согласованностью в распределённой системе | Средняя     | Высокое | Риск двойного списания средств или потери записей.                                         |
| A5 | Vendor lock-in облачного провайдера                  | Низкая      | Среднее | Зависимость от специфических API Yandex Cloud.                                             |
| A6 | Перегрузка событийной шины                           | Высокая     | Среднее | Kafka может не справиться с объемом событий.                                               |
| A7 | Отсутствие observability                             | Высокая     | Высокое | Сложность отладки, невозможно понять причину сбоя.                                         |
| A8 | Каскадный отказ сервисов                             | Средняя     | Высокое | Отказ одного домена вызывает отказ зависимых.                                              |

## 2. Организационные риски

| ID | Риск                                     | Вероятность | Влияние | Описание                                                  |
|----|------------------------------------------|-------------|---------|-----------------------------------------------------------|
| O1 | Сопротивление команд изменениям          | Высокая     | Среднее | Команды привыкли к PowerBuilder и старым процессам.       |
| O2 | Нехватка компетенций                     | Высокая     | Высокое | Kafka, Flink, микросервисы — новые технологии.            |

| O4 | Текучесть экспертов по легаси            | Средняя     | Высокое | Потеря знаний по SQL Server 2008 и PowerBuilder.          |
| O5 | Разные KPI у подразделений               | Средняя     | Среднее | Разные цели → противоречивые требования.                  |
| O6 | Бюджетные ограничения                    | Средняя     | Высокое | Миграция требует инвестиций, бизнес может урезать бюджет. |
| O7 | Отсутствие единого владельца архитектуры | Высокая     | Высокое | Риск разрастания энтропии и дублирования.                 |
| O8 | Недостаточное тестирование               | Высокая     | Высокое | В погоне за сроками могут пропустить тестирование.        |
