# VM модуль для Terraform

## Описание

Этот Terraform модуль создает виртуальные машины с настраиваемыми ресурсами, дополнительными дисками и группами
безопасности. Он поддерживает несколько окружений (dev, stage, prod) с конфигурациями, специфичными для окружения.

## Возможности

- Настраиваемое количество vCPU и объем RAM
- Поддержка дополнительного диска для данных
- Сетевые конфигурации в зависимости от окружения (NAT для не-prod)
- Группы безопасности для production окружений
- Аутентификация по SSH-ключу
- Cloud-init для начальной настройки
- Настраиваемые типы и размеры дисков
- Теги и метки для управления ресурсами

## Требования

- Terraform >= 1.0
- Провайдер Yandex Cloud
- Действительная пара SSH-ключей

## Входные переменные

| Имя               | Описание                          | Тип         | Значение по умолчанию | Обязательный |
|-------------------|-----------------------------------|-------------|-----------------------|--------------|
| vm_name           | Имя виртуальной машины            | string      | -                     | да           |
| vcpu_count        | Количество vCPU                   | number      | 2                     | нет          |
| ram_size_mb       | Объем RAM в МБ                    | number      | 4096                  | нет          |
| disk_size_gb      | Размер дополнительного диска в ГБ | number      | 50                    | нет          |
| disk_type         | Тип дополнительного диска         | string      | "standard"            | нет          |
| subnet_id         | ID подсети для развертывания ВМ   | string      | -                     | да           |
| ssh_public_key    | Публичный SSH-ключ для доступа    | string      | -                     | да           |
| environment       | Имя окружения                     | string      | -                     | да           |
| os_image_id       | ID образа ОС                      | string      | "ubuntu-2204-lts"     | нет          |
| availability_zone | Зона доступности                  | string      | "ru-central1-a"       | нет          |
| platform_id       | ID платформы                      | string      | "standard-v2"         | нет          |
| boot_disk_size_gb | Размер загрузочного диска в ГБ    | number      | 30                    | нет          |
| boot_disk_type    | Тип загрузочного диска            | string      | "network-hdd"         | нет          |
| tags              | Дополнительные теги               | map(string) | {}                    | нет          |

## Выходные данные

| Имя               | Описание                              |
|-------------------|---------------------------------------|
| vm_id             | ID созданной ВМ                       |
| vm_name           | Имя созданной ВМ                      |
| external_ip       | Внешний IP-адрес                      |
| internal_ip       | Внутренний IP-адрес                   |
| disk_ids          | ID подключенных дисков                |
| security_group_id | ID группы безопасности (если создана) |
| vm_fqdn           | Полное доменное имя ВМ                |
| vm_status         | Текущий статус ВМ                     |
| all_vm_details    | Полная карта с деталями ВМ            |

## 1. Инициализация окружения

```shell
cd Task1Advanced/envs/dev/
terraform init
```

## 2. Валидация конфигурации

```shell
terraform validate
```

## 3. Просмотр плана изменений

```shell
terraform plan
```
