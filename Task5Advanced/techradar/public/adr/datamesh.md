# ADR: Внедрение Data Mesh

## Статус
Принято (в процессе Trial)

## Контекст
Компания масштабируется, добавляются новые источники данных, центральная команда аналитики не справляется.

## Решение
Внедрить Data Mesh с децентрализованным управлением данными.

## Последствия
- Data Product Owners в каждом домене
- Self-service инфраструктура
- Федеративное управление качеством
