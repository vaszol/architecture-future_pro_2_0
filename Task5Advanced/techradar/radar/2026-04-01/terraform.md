# Terraform

Terraform используется для управления облачной инфраструктурой как код.

## Обоснование

- Декларативный подход
- Управление состоянием
- Поддержка множества провайдеров
- CI/CD интеграция

## Области применения

- Развёртывание инфраструктуры
- Управление окружениями (dev/stage/prod)
- Backend для state-файлов (S3)
