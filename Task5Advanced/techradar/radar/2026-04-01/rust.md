# Rust

Rust оценивается для высоконагруженных компонентов.

## Обоснование

- Максимальная производительность (C++ уровень)
- Memory safety без GC
- Отсутствие runtime
- Надёжность

## Потенциальное применение

- Критичные по производительности сервисы
- Сетевые компоненты
- Замена узких мест на Go/Java
