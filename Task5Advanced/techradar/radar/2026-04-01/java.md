# Java 17+

Java является основным языком для core banking систем.

## Обоснование

- Стабильность и зрелость экосистемы
- Широкий выбор библиотек и фреймворков
- Строгая типизация и надёжность
- Отличная производительность (JIT компиляция)

## Области применения

- Core Banking системы
- Кредитные конвейеры
- Интеграционные сервисы
