# GitHub Actions

GitHub Actions используется для CI/CD автоматизации.

## Обоснование

- Интеграция с GitHub
- Простая конфигурация YAML
- Большая экосистема actions
- Self-hosted runners

## Области применения

- CI/CD пайплайны
- Terraform apply/plan
- Автоматическое тестирование
- Деплой в облако
