# Apache Flink

Flink используется для сложной stream processing.

## Обоснование

- Exactly-once семантика
- Event time processing
- Stateful вычисления
- Высокая производительность

## Области применения

- Real-time аналитика
- Сложные event processing
- Потоковые ETL
