# Kubernetes

Kubernetes используется для оркестрации микросервисов.

## Обоснование

- Автоматическое масштабирование
- Self-healing
- Declarative configuration
- Multi-cloud support

## Области применения

- Оркестрация микросервисов
- Развёртывание ИИ-сервисов
- Управление инфраструктурой
