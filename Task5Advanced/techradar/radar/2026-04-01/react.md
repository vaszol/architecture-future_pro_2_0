# React 18

React используется для портала самообслуживания и UI компонентов.

## Обоснование

- Компонентный подход
- Высокая производительность (Virtual DOM)
- Большая экосистема и сообщество
- TypeScript поддержка

## Области применения

- Портал самообслуживания
- BI дашборды
- Административные интерфейсы
